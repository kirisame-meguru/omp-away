## Recording a run

Use the [operator procedure](../DEBUG.md) and [confirmation capture](decision-trace.md). Only the orchestrator may supply observed run outputs. Do not create synthetic evidence bundles, example pass records, transcripts, screenshots, secret material or arbitrary `adb logcat`/packet dumps here. Never commit raw capture, QR/clipboard, notification dump, SDP, paid session journal or a credential filepath. Treat even the plaintext HTTP request used for offline projection as credential-bearing.

After a real run, privately inspect each artifact for sensitive material and unexpected fields. For the positive run the sanitized allowlist is `scenario.json`, `host.ndjson`, `decision.ndjson`, `android.json`, `network.json`, `invite.json`, `relay.json` and the actual offline verifier status. Add a **new**, dated, non-overwriting run directory only after that review and receipt of actual observed output. Record the run's UTC window, exact component revision/host version, Android build/APK hash/serial, selected route, capture source/coverage and clock uncertainty, component gate results, and owner-witnessed human actions. Include separately identified negative cases and measured outcomes/observation windows. Explicitly list missing artifacts, failures and inconclusive cases; never translate missing into success. Retain a SHA-256 manifest of the reviewed projections; sign the manifest with the operator's established release signing workflow or store it in access-controlled immutable storage. Record the immutable revision or digest reference, never edit that run in place, and do not claim a digest alone authenticates its author.

The release decision also requires actual component gate outputs: relay `go test ./...`; plugin `bun test` and desktop media `uv run --project media pytest media/tests`; Android `gradlew.bat :app:testDebugUnitTest :app:connectedDebugAndroidTest` on the leased serial. Android gate counts above were supplied by the orchestrator, not produced by the acceptance harness. Component gates, deployment smokes and the paid voice run are distinct.
