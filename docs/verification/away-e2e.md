# Away verification evidence

Historical captured-session records and device-specific observations are not distributed in this repository. Their removal does not establish or invalidate any behavior of the current build.

Use the [operator procedure](../DEBUG.md) and [confirmation capture procedure](decision-trace.md) for an explicitly authorized run. Keep raw captures, transcripts, device identifiers, endpoint addresses, credentials and per-run evidence outside the repository in protected local storage.

Record actual commands, component revisions, tool versions, measured results and limitations privately. Report only redacted summaries approved for disclosure; do not commit captured payloads or manufacture passing evidence. Local integration is not publication approval.
